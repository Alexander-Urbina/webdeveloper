ScanToCAD

AI-powered Scan-to-BIM Automation Platform

Description

A comprehensive SaaS platform that automates the conversion of 3D point cloud scans into architectural CAD (DXF) and BIM (IFC) models using Artificial Intelligence. The system streamlines the scan-to-BIM workflow by automatically identifying and reconstructing architectural elements from raw 3D data.

It features a distributed serverless architecture capable of processing large point cloud files, integrated payment processing, and a custom high-performance 3D viewer.

Job Done

  1. Designed and implemented the complete system architecture.
  2. Developed the Next.js 15 frontend with a custom 3D viewer based on Three.js and web-ifc.
  3. Built the Python FastAPI worker for orchestration and geometry processing (DXF/IFC generation).
  4. Deployed and optimized the SpatialLM AI model on a serverless GPU infrastructure.
  5. Integrated payment processing with Stripe and file storage with Cloudflare R2 and Supabase.
